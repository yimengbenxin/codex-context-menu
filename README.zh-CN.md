# Codex 上下文 · 0.6.4 试用版

独立 macOS 工具，无需在聊天里发“改上下文”的指令。非 OpenAI 官方产品。

## 安装前必读

当前只支持 macOS 14+、Apple Silicon、Python 3.11+，以及 `compatibility.json` 中已验证的官方 0.159.2 CLI / Node 哈希。
官方文件必须位于 `/Applications/ChatGPT.app/Contents/Resources` 的 `codex-cli/CodexCLI.app` 与 `cua_node/bin/node` 布局。
其他版本、不同 Codex.app 布局、Intel、Windows 暂不支持；安装前检查不通过就退出，不修改你的安装。

Python 可使用 Codex 管理的现有运行时，或 `/opt/homebrew/bin/python3`、`/usr/local/bin/python3`，需为 3.11+。
普通使用不需要安装第三方 Python 包。应用为本地签名，未获 Apple 公证；核对下载来源及校验值后，按系统提示手动批准运行，不关闭系统安全保护。

## 下载与使用

1. 从 GitHub Releases 下载 ZIP 或 DMG，按 `v0.6.4-SHA256.txt` 校验。
2. 解压或挂载，双击 `Install.command`；不要拆开同目录的应用和安装脚本。
3. 安装程序会备份旧安装，放入 `~/Applications` 并建立本工具的登录启动项；不需要管理员权限。
4. **首次启用整个 Codex 的启动接入时重启一次，不是每个对话都要重启。** 更新运行组件也需加载新版本；普通模式切换无需重启。
5. 在工具中点击“识别当前对话”，或点击链接框按 ⌘V 粘贴 `codex://threads/对话ID`，再点“定位链接”。多窗口无法确定目标时使用链接。
6. 默认范围是“仅此对话”；项目范围需明确选择。选择策略、保存，然后下一轮检查“最近运行窗口”。

## 策略逻辑

- 官方默认：清除当前范围覆盖，继承项目、上级及官方设置，不固定 272K 或模型。
- 自定义：输入整数 K，485 表示 485000；留空清除覆盖。实际窗口受官方保留比例和模型上限约束。
- 自适应：档位来自官方初始值、算术中间值、上限。自动压缩成功后保留比例 ≥65% 升档，45%～65% 连续两次成功也升档；手动或失败压缩不升档。
- 从自定义切回自适应，会恢复同一范围/模型/配置版本原先保存的自适应档位；没有有效档位则从官方初始值开始，**不会从自定义数值继续爬升**。
- 下一轮加载，不修改正在生成的回复。保存成功不是运行成功；其他订阅者或不能完整保留的权限策略可能阻止切换。
- 当前只是菜单栏伴随应用；Dock 常驻、菜单栏直接选择三种策略和双击拉起属于后续版本，不包含在 0.6.4。

## 隐私与限制

不改官方应用、全局 TOML、模型缓存或聊天历史，不上传聊天。对话级只写工具状态，项目级明确修改所选项目配置并备份。
本地 Token 统计禁止联网；账户额度由固定版本 CodexBar 使用现有认证访问官方 OpenAI，可能进行正常 OAuth 刷新；自动刷新默认关闭，不读取浏览器 Cookie。
运行日志只包含白名单预算/确认元数据。恢复会话可能暂时影响缓存命中，不能承诺零缓存成本。
真实超长对话的自适应升档尚未完整验收；隔离生命周期测试不等同于长期质量验收。

更多架构、测试命令、卸载恢复和许可证说明见 [English README](README.md)。ZIP 与 DMG 内容相同，不包含私人日志、登录凭据或官方运行程序。
