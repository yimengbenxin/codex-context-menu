# EXTEND · 菜单栏快捷设置与默认值

复用 ContextSettingsModel / ContextBackend 的修订、验证、保存及下一轮加载合同。菜单栏使用独立表单实例，避免覆盖主设置窗口尚未保存的输入；不增加第二套设置写入逻辑。焦点定位收敛到已有 FocusedContextTarget，仍只读取标题并只读核对本地索引。

阈值默认值由 adaptive/defaults.json 唯一持有，Python 配置生产者与 Node 策略消费者读取同一文件，Swift 使用生产者返回的默认值。默认阈值不写成显式覆盖；旧的显式 45 / 65 保留，用户恢复默认后改用 35 / 55。

档位预览复用 Node modelBounds；对话模型只读来自本地索引，项目模型来自配置层。缺失元数据时显示无法读取，不猜模型或固定 272K / 872K。预览只用于显示，不改运行状态。额外元数据边界低于 200 行，不承担状态机或模型路由。

右键打开原生菜单，三种策略打开小型确认表单；单击显示菜单，双击取消延迟菜单并拉起主设置窗口。快捷操作始终仅此对话，不隐式改项目。权限或目标核对失败时保留错误且禁用保存，提供深度链接和主窗口入口。

验收覆盖默认/显式参数往返、35/55 边界、旧设置保留、官方数值预览、快捷与主表单隔离、点击分派、包资源及原生下一轮生命周期。主 Codex 不在测试过程中重启或修改程序文件。
