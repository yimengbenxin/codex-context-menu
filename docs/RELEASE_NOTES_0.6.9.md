# Codex 上下文 v0.6.9：压缩用量重建估算

## 本次更新

- 修复把最近报告用量直接作为完整压缩判定用量统计的问题。这是程序的通用读取链路更新，不是手工修正一条历史记录。
- 今后采集压缩样本时，自动只读对应本地日志，重建新增工具结果与历史加密推理的长度估算；已有样本也通过相同算法展示。
- 界面分开展示报告前输入、报告合计、新增本地结果、历史推理补计以及“不补计 / 补计”两种条件估算。例如报告合计234.1K，补上约0.1K本地结果和约28.4K历史推理后，显示约234.2K–262.6K。
- 越线率、目标超过量P95和参考建议采用明确标注的估算口径，同时列出不补计口径。不再把缺失或无法重建的样本当成未越线或0%。
- 新估算模块随应用打包，并纳入安装后的资源校验。官方内核保持原版签名；本次不改变压缩模型、推理强度、预算或压缩百分比。

## 数据与限制

只读本地日志的条目角色、内容长度和时序，正文立即丢弃；仅保存数字与必要标识，不保存或上传聊天、代码、加密内容或凭据，不改写官方聊天记录。旧观测的原始报告值不改写。

接口尚未报告服务端是否已包含历史推理，因此补计只是条件假设，两种数值不是内核精确计数或严格置信区间；估算超过设置目标不能证明真实触发原因。至少10条可重建成功自动样本、覆盖率80%才提供估算建议，不自动应用，也不保证未来越线概率。

## 验证与安装

- 116项单元检查：40项Swift、32项Node、44项Python，无跳过。
- 官方签名0.159.2隔离后端的22条新合成压缩样本，验证新增记录包含通用重建字段、重启与历史完整性；发布包解包后再次验证。
- 本机已确认更新后的界面和只读统计读取正常，重启后运行组件加载正常。合成验证不是压缩速度、质量或真实长对话触发线的完整验收。
- 提供macOS Apple Silicon的DMG、ZIP及SHA-256文件；其他运行版本仍按协议能力检测，不宣称全部兼容。

仍沿用兼容范围有限的试用版发布策略。首次安装接入运行组件需完整退出并重开Codex一次；不是每个对话都要重启。已接入后的设置切换在下一轮加载。
