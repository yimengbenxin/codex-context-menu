# Codex 上下文 0.6.6 · 菜单栏快捷设置与可跟随的默认值

本次提供 macOS 14+ / Apple Silicon 的 DMG、ZIP 和 SHA-256 清单。非 OpenAI 官方产品，仍是实验性试用版；官方 CLI 0.159.0 / 0.159.2 的协议验收不等于所有版本或真实长历史均已验收。

## 菜单栏直接操作

- 右键菜单栏项目，进入“修改当前对话上下文”，选择官方默认、自适应、自定义。
- 小面板核对焦点对话，仅修改此对话；自定义直接输入 K 并保存，不需要发送聊天消息。
- 焦点识别需要辅助功能权限；不能识别时可在小面板原生粘贴深度链接，不猜后台对话。
- 快捷面板与完整窗口复用同一保存逻辑，各自保留表单，不覆盖主窗口未保存的草稿。
- 单击打开菜单，双击拉起完整设置。Dock 常驻仍未提供。
- 默认用小图标避免菜单栏长统计文字挤占空间，可取消“菜单栏仅显示图标”恢复统计文字；应用激活时，顶部“上下文”菜单也提供同一快捷入口。

## 灰色默认数值

- 默认升档阈值统一改为两次 **35%**、一次 **55%**。
- 阈值与三档输入框留空时显示灰色默认数字，留空保存使用默认，不把默认阈值永久写死为显式覆盖。
- 旧版已保存的显式 45 / 65 或其他自定义值保留。点击“恢复默认阈值与官方档位”并保存才使用新默认。
- 初始与上限读取目标模型的官方本地目录，中间档默认为算术中点。例如 272K / 872K 对应 572K 中间档，非固定 485K。
- 缺少或重复模型元数据时明确显示未读取；不会用固定数字或猜测模型填充。

**35 / 55 是成功自动压缩后的保留比例升档规则，不是压缩触发线。** 两次区间连续满足才升一档，一次线达到即升一档；手动或失败压缩不升档。新档位在下一轮加载，不打断生成。切回自适应仍从初始档重新开始。
