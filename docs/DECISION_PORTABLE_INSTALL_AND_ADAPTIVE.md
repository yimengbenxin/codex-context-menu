# 跨设备安装与可配置自适应

## EXTEND：以安装器和策略模块为唯一权威

业务目标：拖入应用后可以在原生窗口完成组件接入；兼容性依赖实际协议能力而非发布机的固定程序哈希；阈值和三档预算可以按当前范围配置；自定义切回自适应从初始档重新开始。

已确认：0.6.4 安装器要求执行同目录 Install.command，单独复制 .app 不创建支持目录或启动接入。安装器、shell 后端、Node 启动及能力检查重复写死 ChatGPT.app 路径和发布机哈希。线程测试写死解释器缓存路径，已修正并通过远端完整 CI。

方案比较：只改错误提示不能补齐安装；移除所有检查会把不支持会话恢复的版本误判为兼容；增加独立安装调度器会产生双重状态所有权。因此复用现有安装器，增加仅接入模式并嵌入应用。新增一个只读官方程序定位/签名/协议探测单元，不承担配置或预算业务，控制在 200 行内；安装器将结果写入现有 manifest，启动消费者只使用该权威描述。不同版本通过必要方法与字段检查后允许接入，无法据此宣称所有版本都通过真实长对话验收。

自适应参数继续由现有项目配置 / 对话状态持有，策略模块消费统一参数。默认阈值 45 / 65，档位来自官方模型初始值、算术中间值、上限；不是固定 272 / 485 / 872。显式切回自适应更新激活代次，旧预算状态失效而不删除聊天或兄弟范围状态。参数和代次参与已有修订合同；不另建预算状态机。

验收覆盖：全新用户目录及仅 .app 接入、失败回滚、不同官方路径/版本、缺失协议拒绝、预算和默认模式不变、阈值与档位配置、下一轮与重启恢复、自定义返回初始档、对话隔离、实际原生界面与远端 CI。官方身份签名和历史保护保留；不关闭系统校验。
