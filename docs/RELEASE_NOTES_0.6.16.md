# Codex 上下文 v0.6.16

本次汇总 0.6.9 之后已完成的本机维护更新，提供 macOS Apple Silicon 的 DMG、ZIP 和 SHA-256 校验文件。

## 更新内容

- 全部折叠标题支持整行点击：文字、箭头及右侧空白都能展开或收起，包含项目、每日和来源的嵌套明细；保留原生键盘与辅助功能操作。
- 修复设置窗口无故抢焦点：后台重新打开不激活窗口，异步定位完成不再次置顶；手动打开仍正常。
- 自适应支持降档：连续两次成功自动压缩后的保留量严格低于相邻低档预算乘以低阈值时，回退一级。手动、失败或未知样本打断计数。
- 补齐任务的安全启动边界预算加载；不会为应用配置而自动暂停正在执行的目标，活动任务内部续跑不能保证立即换档。
- 减少后台访问项目目录，避免因不必要的后台文件检查反复引出系统授权；明确保存项目设置时仍可能需要系统权限。
- 集成官方 CodexBar 0.70.0 CLI 及 MIT 原生展示组件：额度窗口、重置时间、Credits、费用参考，以及输入、缓存读取、未缓存输入、命中率、输出和推理 Token。
- 支持近 7 天、近 30 天、本月及全部历史，以及每日模型、项目和会话来源明细。未报告字段明确显示未知，不用零代替。
- 默认入口仍为上下文；菜单栏提供独立用量入口，不读取浏览器 Cookie。
- 发布与 CI 测试入口统一覆盖全部 Swift、Python 和 Node 测试，包含降档、后台文件访问、用量展示及窗口焦点回归。

## 安装和兼容性

仅支持 macOS 14+、Apple Silicon；需要 Python 3.11+。官方 CLI 0.159.0 / 0.159.2 有既有验收记录，其他版本依据实际签名和协议能力检查，不宣称全部兼容。

首次完整接入或更新运行组件后，需完整退出并重开整个 Codex 一次；不是每个对话都要重启。接入后的设置切换在下一安全对话启动边界加载。仅修改此版本的界面无需重启主 Codex。

应用使用本地临时签名，未使用 Apple Developer ID 签名及公证；安装不关闭 Gatekeeper、不绕过签名检查，不修改或重新签名官方内核。

## 验证与边界

发布前重新通过 56 项 Swift、50 项 Python 和 76 项 Node 检查，共 182 项，无跳过。0.6.16 已实测标题和空白区域点击，包含嵌套每日明细；安装包签名、私人运行文件排除及解包后的原生隔离金丝雀通过。本次检测到官方 CLI 已更新为 0.160.0，协议检查和隔离合成路径通过，不据此宣称该版本所有桌面能力或长期稳定性完成验收。源码测试和合成验收不等于真实长对话、所有安装布局或长期稳定性证明。

本地 Token 不是订阅账单或所有设备消费；费用是可计价部分的 API 标价参考。历史扫描不完整、缺失日志和未定价模型会导致统计不全。官方额度读取使用现有登录凭据访问官方接口；不上传聊天、代码或凭据给社区作者。压缩观测是有明确假设的本地估算，不冒充内核精确计数。

仍保留兼容范围有限的试用版标记。不包含换模型压缩、修改压缩推理强度或压缩加速插件。
