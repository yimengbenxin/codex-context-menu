# Codex 上下文 0.6.8

本次公开发布仍标记为实验性试用版。支持macOS 14+、Apple Silicon、Python 3.11+及符合签名与协议检查的官方Codex运行时；不是所有安装方式都已完成长期验收。

## 新增

- 自动压缩线可填写1–99%的整数，留空继承默认；超过90%显示红色越线提示。
- 压缩目标不得超过模型原始最大上下文的90%。保存时校验，模型或自适应档位变化后重新限幅；保留官方签名内核，不修改模型或推理强度。
- 本地压缩观测：记录最近报告的压缩前输入/总量、压缩后总量、耗时及结果，显示观测预算越线率和最近记录。超过触发线是正常触发，未知、手动和失败单列，不误算成未越线。
- 至少10条可比成功自动样本、覆盖率80%后给保守百分比参考，不自动应用，也不保证换挡后的因果概率。观测值不是服务端精确请求大小。
- 刷新统计不会覆盖未保存设置。数字元数据只存本地工具数据库，项目路径哈希化，最多10000条；不保存聊天正文、代码或凭据，不上传。

## 验收与发布检查

- 112项自动检查：40项Swift、32项Node、40项Python，无跳过。
- 官方签名0.159.2隔离金丝雀：272K预算、95%触发线，两组各11次自动压缩。270.005K组不越预算并保留95%；280.005K组超过预算8.005K，保守参考92%。冷重启后样本保留，对话隔离、历史前缀、数据库完整性及主配置/官方程序摘要通过。
- ZIP解包后用包内资源重复同一原生金丝雀，并检查签名、安装器、版本、源码资源一致性及无私人运行数据。DMG创建后验证映像完整性。
- 复测伴随界面的重新读取、跨项目与统计刷新，未覆盖未保存草稿。真实超长对话、所有插件及长期稳定性仍不是本次已证明范围。
- 修正包校验写死旧版本的问题；CI和发布验证加入观察器、统计及压缩设置测试。
- 修复包解压目录或符号链接路径下档位预览为空的问题，并加入回归检查；Swift验证统一使用独立临时构建目录。

## 更新安装

下载ZIP或DMG及SHA256校验文件；拖入Applications后打开，点击“完成组件接入 / 重新验证”，或保持安装脚本与应用在一起运行Install.command。

**更新运行组件后，需要完整退出并重新打开整个Codex一次，加载新增采集逻辑。不是每个对话都要重启；之后设置在下一轮生效。** 本次验收不会替你重启主Codex。新安装不倒填历史，无样本时不会伪造概率或建议。

应用使用本地临时签名，未做Apple Developer ID公证；请核对来源后按系统提示批准运行，不关闭Gatekeeper。官方CLI不会被替换或重新签名。0.159.0生命周期兼容性沿用此前验收，本次观测金丝雀在0.159.2验证。
