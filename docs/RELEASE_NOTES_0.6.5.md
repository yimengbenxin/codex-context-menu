# Codex 上下文 0.6.5 · 跨设备接入与自适应设置

本次修复单独拖入应用后运行组件缺失、版本绑定过严、多对话焦点定位及测试解释器依赖本机路径的问题，并开放自适应参数设置。非 OpenAI 官方产品，仍为试用版。

## 安装不再依赖记住一条脚本

将应用拖入 DMG 的 Applications 入口，再从应用目录打开。首次窗口提供“完成组件接入 / 重新验证”按钮，直接检查并安装本工具的运行组件；只挂载 DMG、只复制 .app 或重启 Codex 都不能替代接入步骤。

也保留 Install.command 的备份安装方式。缺少组件时明确说明原因，不再只显示含糊的“对话级组件不可用”。

首次接入、或这次更新运行组件后，需要完整退出再打开整个 Codex 一次；不是每个对话都要重启。接入完成后的策略切换和升档仍在下一轮加载。

## 按协议能力兼容，不强制同一 CLI 版本

已使用带 OpenAI 身份签名的官方 CLI **0.159.0 和 0.159.2**，分别完成隔离生命周期验收。安装时检查官方签名与实际所需的会话读取、恢复、取消订阅、配置读取和窗口反馈接口，而不是要求二进制等于发布机的固定哈希。

不同版本通过所需协议检查后可以接入；检查失败给出具体原因，不绕过官方签名。安装器记录本机接受的路径和哈希，后续官方更新导致变化时可在工具中重新验证。支持系统或用户 Applications 下的 Codex.app / ChatGPT.app 内已识别的 CLI / Node 布局。

这不代表所有官方版本、桌面布局或插件都完成了真实使用验收。仍要求 macOS 14+、Apple Silicon、Python 3.11+；Intel、Windows 和 Linux 暂不支持。应用为本地临时签名，未获 Apple Developer ID 签名及公证。

## 自适应可配置

- 两次触发线与一次触发线可修改，默认 **45% / 65%**，例如改为 **30% / 50%**。
- 初始、中间、上限三个档位可分别输入整数 K，留空跟随对应官方参数。
- 初始与上限留空取官方值；中间档留空时取当前初始与上限的算术中点，包含自定义端点。
- 默认档位不是固定 272 / 485 / 872：来自官方初始值、初始与上限的算术中点、官方上限。
- 阈值须满足 0 ≤ 两次触发线 < 一次触发线 ≤ 100；档位须有序，最终预算仍受官方模型上限约束。
- **自定义切回自适应从初始档重新开始**，不恢复旧的自定义预算或历史升档；初始档留空时使用官方初始值。
- 配置和激活代次参与现有修订合同；正常保持自适应并重启时，恢复同一代次的已升档状态。
- 手动或失败压缩不升档，仍由 Codex 官方后端压缩；没有换模型或压缩强度优化。

## 多对话焦点识别

优先读取当前或最近选中的 Codex 窗口中应用 WebArea 的标题，通过只读本地索引精确匹配唯一 ID，再核对桌面会话元数据。界面显示对话名称和“定位来源：窗口焦点”。

不把最新后台订阅当成焦点。同名、非对话页或定位期间焦点变化时不猜测，提示使用深度链接。失败后旧目标被标记，保存被阻止。

焦点识别需辅助功能权限：系统设置 → 隐私与安全性 → 辅助功能 → Codex 上下文。缺少权限时提供设置入口，不自动替用户批准；深度链接不需要此权限。系统权限本身较宽，本工具实现只读取窗口标题，不控制 Codex UI，也不遍历聊天正文。

## CI、验收与限制

- 测试子进程改用当前 Python 或显式配置的解释器，不依赖开发机的 Codex 缓存路径。此前失败的 GitHub CI 已修复，线程与安装器步骤完整执行。
- 共 **80 项单元检查**：Swift 33、Node 24、项目配置 11、对话配置 3、安装器 3、自适应参数 3、协议 3。
- 两个 CLI 版本均验证了 30 / 50 阈值、320K / 550K / 800K 档位、下一轮升档、自定义切回初始档以及重启保持；这是隔离合成响应测试，不是真实长对话质量评测。
- 全新用户目录、只复制应用后的接入、失败回滚及数据库完整性有相应夹具；不把文件系统夹具等同于一台真实全新 Mac 的完整验收。
- 焦点诊断确认前台对话可以不同于后台订阅；本机伴随应用的权限需用户授权。
- 真实超长对话自适应升档、真实多窗口连续切换、所有插件兼容及长期稳定性尚未完整验收。缓存重用可能暂时下降，不承诺零成本。
- Dock 常驻、菜单栏直接切换三种策略及双击拉起仍是后续迭代。
