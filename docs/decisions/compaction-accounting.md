# EXTEND：压缩统计的报告值与重建估算

端到端目标：用户能对上最近报告值、新增工具结果、历史推理补计和压缩判定的估算，不再把请求用量冒充内核触发计数。

源头修复 SQLite 报告所有者的统计合同，复用现有观察器、同一数据库和界面；不新增控制器、不修改官方内核、不重启主 Codex。薄日志转换模块限于 200 行以内，只读解析官方 rollout 的角色、内容长度和时序，立即丢弃正文；不存储或上传聊天、加密内容、代码或凭据。

从最近报告合计补上最后模型条目之后的本地结果估算，再单列最近真实用户边界之前的加密推理估算。接口不报告服务端是否包含历史推理，因此展示不补计/补计两种条件估算；这些不是精确值或严格置信区间。统计和推荐使用注明补计假设的估算，不用空缺样本凑出 0%。旧记录按同一算法重建，日志不可读、回滚无法重建或内容类型不支持时保留报告值并标为未知。

回归覆盖已有记录、新增采集、重复写入、多个对话、缺失日志、回滚、未知内容、报告值与估算相差 28K 的场景、UI 解码和真实本机旧样本读取。修改只更新伴随工具，不替换正在运行的官方内核或写入聊天文件。
