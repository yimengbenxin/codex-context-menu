# CodexBar 0.70.0 visual authority

Decision: REUSE the latest stable upstream CLI and native visual primitives; EXTEND the existing menu/window consumers, not the statistics producer or scheduler. The preceding 0.6.13 dashboard was an original large-metric grid, not a CodexBar replica, and is replaced rather than polished.

Authority: CodexBar v0.70.0, its release asset hashes and fixed source; docs/codexbar.png plus UsageMenuCardLayout, MetricRow, UsageProgressBar, MenuHighlightStyle and SettingsPane. Use the upstream 310-point menu card, 20-point horizontal insets, system body/footnote typography, six-point progress tracks, grouped quota/reset/pace rows, Cost and Credits sections and ordinary native menu actions. Context remains the default entry and conversation controls remain intact. This app adds a context tab rather than fake or non-functional providers/account-switching actions.

Copy reusable MIT-licensed rendering code with preserved license/provenance; bind existing native-data reports through one bounded presentation model. No pricing, OAuth, credentials or refresh ownership moves into rendering. Preserve file-read/network restrictions, missing-value semantics, all existing token/history details and actual Codex process/configuration. Defaults that differ because official account windows are missing are data differences, not invented UI values.

Validate actual native reference tokens and visible layout, menu-to-window navigation, compact details, period queries, old unknown/error states and packaged latest CLI. Use one batched visual pass and at most one confirmation pass. Do not claim pixel equality across different live data, platforms or extra context functionality without measured evidence.

Local acceptance: latest stable release was verified as v0.70.0 through the official GitHub API. The pinned CLI passed the unchanged three native sandbox/cold/incremental tests. The application passed 76 Node, 49 Python and 53 Swift checks. Its real macOS window displays the compact Codex quota/Credits/cost card, native sidebar, complete Token/cache rows, history chart and project disclosures. The native usage menu exposes the same card and successfully returns to the window. Native menu screenshot capture is unavailable through the configured UI tool; do not present that as a screenshot or pixel-equality acceptance. Main Codex is not restarted or re-signed by this UI update.
