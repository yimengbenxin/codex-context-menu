# EXTEND：本地压缩观测与建议

复用官方签名内核、现有通知流和下一轮设置控制器。不替换内核，不代理模型请求，不开启官方调试分析捕获（该入口只在调试构建可用），不读取账号凭据；本地重建仅解析对应日志条目和内容长度，正文立即丢弃，不保存或上传。

`thread/tokenUsage/updated` 提供最近报告值；以 `contextCompaction` 的开始、完成和回合结束事件关联压缩。原始报告值不足以解释完整触发计数，后续按[重建统计合同](compaction-accounting.md)只读对应日志的内容长度，增加本地结果和历史推理的条件估算。界面明确区分报告值、不补计/补计估算，不声称真实精确概率。默认设置目标未由接口报告时不猜测为95%或90%。

薄事件转换由独立观察器负责，不改预算/模型/推理强度、不拦截或等待正常对话。数字记录、去重、保留、分组和建议由一个本地SQLite业务模块拥有；多进程用数据库事务统一写入。界面与预览只消费其报告，不另写推荐算法。只写工具自己的数据库，最多保留10000条，权限0600。失败不阻断对话。

按项目、对话、模型、预算、设置百分比与作用域分组；手动、失败和无法重建的样本独立显示，不算成未越线。补计口径的估算与预算比较，不补计口径同时展示；估算设置目标超过量另列，不视为失败，也不能证明触发归因。至少10条可重建且目标已知的自动成功样本、覆盖率至少80%才给含推理补计假设的估算建议；仍受已有模型安全线和99%上限约束，不自动应用，不能保证实际或未来越线概率。

验证覆盖通知顺序、重复、缺失、失败、手动、多个对话、重启、并发写入、坏数据库和隐私白名单；再使用隔离官方后端验收实际记录与读取链路。主Codex不自动重启，测试不写入主聊天记录。
